# 1. 생성 패턴 (Creational Patterns)

생성 패턴은 **객체 생성 메커니즘**을 다루는 디자인 패턴입니다.  
객체를 직접 생성하는 대신, 특정 상황에 맞는 객체를 생성하는 과정을 캡슐화하여 코드의 유연성을 높이고 재사용성을 극대화합니다.

### 왜 사용하는가?

객체를 생성하는 로직이 복잡하거나, 어떤 구체적인 클래스의 인스턴스를 만들어야 할지 클라이언트 코드로부터 분리하고 싶을 때 유용합니다.  
이를 통해 시스템 전체의 결합도를 낮추고, 새로운 클래스가 추가되거나 변경될 때 코드 수정을 최소화할 수 있습니다.

### 이 카테고리의 패턴들

* **싱글턴 패턴 (Singleton Pattern):** 오직 하나의 인스턴스만 생성되도록 보장합니다.
* **팩토리 메서드 패턴 (Factory Method Pattern):** 객체 생성 과정을 서브클래스에 위임합니다.
* **추상 팩토리 패턴 (Abstract Factory Pattern):** 관련 객체들의 집합을 생성하는 인터페이스를 제공합니다.
* **빌더 패턴 (Builder Pattern):** 복잡한 객체를 단계별로 생성합니다.
* **프로토타입 패턴 (Prototype Pattern):** 기존 객체를 복제하여 새 객체를 생성합니다.
