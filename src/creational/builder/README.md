# 빌더 패턴 (Builder Pattern)

### 1. 목적 (Intent)

복잡한 객체를 생성하는 과정과 그 표현 방법을 분리하여, 동일한 생성 절차에서도 서로 다른 표현 결과를 만들 수 있게 하는 생성 패턴입니다.

### 2. 문제 (Problem)

생성해야 할 객체의 필드가 많고, 그중 일부는 선택적으로 설정해야 할 때 생성자가 매우 복잡해집니다.  
수많은 파라미터를 가진 하나의 생성자를 쓰거나, 다양한 조합의 생성자를 여러 개 만드는 '점층적 생성자 패턴'을 사용하면 가독성이 떨어지고 유지보수가 어려워집니다.

### 3. 해결 (Solution)

빌더 패턴은 객체 생성을 **빌더(Builder)**라는 별도의 클래스에 위임합니다.

* 클라이언트 코드는 원하는 값들만 빌더 객체에 순서에 상관없이 설정합니다. (`setAge()`, `setAddress()` 등)
* 모든 설정이 끝나면, 빌더의 `build()` 메서드를 호출하여 최종적으로 완성된 객체를 얻습니다.
* 이를 통해 객체 생성 과정이 매우 직관적이고 읽기 쉬운 코드가 됩니다.

---

### 시나리오

필수 값(`email`, `nickname`)과 여러 선택 값(`age`, `address` 등)을 가지는 `User` 객체를 생성합니다.

* **Before:** 점층적 생성자 패턴의 문제점을 코드로 확인합니다.
* **After:** 빌더 패턴을 적용하여 `User` 객체를 유연하고 안전하게 생성하는 방식으로 리팩토링합니다.
